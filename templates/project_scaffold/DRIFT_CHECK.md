# DRIFT CHECK

Run before major work, release, or shutdown.

- `CURRENT_TASK.md` does not contradict live state or git state.
- Next exact step is current and actionable.
- Paths do not contain stale home/office mismatches.
- `AGENTS.md` and `README.md` do not contain conflicting rules.
- Commands are current and not deprecated.
- Untracked files are reviewed and either added, ignored, or documented.
- Working tree is clean or dirty files are intentionally documented.
- Release notes are current.
- Task status is current.
