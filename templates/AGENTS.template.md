# AGENTS

## Startup Discipline

- Always read CURRENT_TASK.md first.
- Confirm working directory and active project before any action.
- Do not assume context from previous sessions.

## Change Discipline

- Prefer minimal reversible changes.
- Respect project scope boundaries.
- Do not make destructive changes without explicit approval.
- Prefer checked-in docs over memory.
- Stop on uncertainty.

## Work Separation

- Separate audit, planning, code, deployment, and cleanup.
- No live external mutations unless explicitly authorized.
- Update CURRENT_TASK.md before major handoff/shutdown.
