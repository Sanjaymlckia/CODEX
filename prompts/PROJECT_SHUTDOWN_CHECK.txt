CodexHub project shutdown check.

Rules:
- Read `CURRENT_TASK.md` first.
- Run `git status -sb`.
- Detect dirty and untracked files.
- Detect stale task text, stale next steps, path mismatches, and obvious contradictions between checked-in docs and git state.
- Update `CURRENT_TASK.md` with current truth only if authorized.
- List the next exact command for the next session.
- Do not commit unless explicitly authorized.
- Do not mutate runtime systems.

Default report:
1. Current project/path.
2. Git status summary.
3. Current task summary.
4. `CURRENT_TASK.md` update/check result.
5. Snapshot/checklist location if created.
6. Resume state file location and saved Codex session ID, if created.
7. Drift state: `CLEAN`, `WARNING`, or `BLOCKED`.
8. Dirty or untracked files.
9. Stale-state findings.
10. Recommended `CURRENT_TASK.md` update, if any.
11. Next exact command.
12. Final concise resume block:
   - Project
   - Machine
   - Path
   - Git status
   - Last completed action
   - Pending next action
   - Resume readiness: READY / BLOCKED
   - Recommended next launch mode: resume / reconstruct
   - Notes
