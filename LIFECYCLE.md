# Lifecycle States

Lifecycle states are the institutional truth layer. They describe the learner or customer relationship over time and are not the same as operational pipeline stages.

## Canonical Lifecycle States

| State | Meaning |
| --- | --- |
| Prospect | Known person or organization before formal application. |
| Applicant | Application or intake process has started. |
| Registered | Accepted or registered before active learning begins. |
| Active Learning | Currently participating in learning delivery. |
| At Risk | Active learner requiring intervention or monitoring. |
| Completed | Program or course completed. |
| Alumni | Post-completion relationship. |
| Withdrawn | Exited before completion. |

## Rule

Lifecycle != Pipeline.

Lifecycle should not be used to record operational messages such as reminder sent, invoice sent, or WhatsApp follow-up.
